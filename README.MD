# 🔄 Spring Boot JPA Many-to-Many Example

A Spring Boot application demonstrating how to implement and manage a **Many-to-Many relationship** using **Spring Data JPA** and **Hibernate**.

---

## 📝 Description

This project showcases how to use JPA annotations to model a many-to-many relationship between two entities. It handles:

- Bidirectional and unidirectional many-to-many mappings
- Cascade operations and fetch strategies
- Best practices for mapping and querying relational data

---

## ⚙️ Technologies Used

| Technology         | Purpose                                      |
|--------------------|----------------------------------------------|
| Java 17+           | Programming language                         |
| Spring Boot        | Application framework                        |
| Spring Data JPA    | Simplified data access and ORM integration   |
| Hibernate ORM      | JPA implementation                           |
| Maven              | Build and dependency management              |
| H2 / MySQL         | Relational database (configurable)           |
